# 最后四项真人真机验收

更新：2026-10-30。目标设备为当前已安装 Bridge 0.2.0、Agent 0.3.31、App 0.3.6 的 iPhone 11。以下操作需要持有手机的人完成；每项结束后记录 BeanBao 的状态和实际前台画面即可，不需要提供 Key、私钥或个人备忘录内容。

1. **物理拔线运行。** 手机保持已越狱、解锁、亮屏并可联网，拔掉 USB 数据线。在 BeanBao 选择“模拟模型”，输入“打开设置”并点“开始”；确认状态为完成、设置在前台。再打开 BeanBao，选择 Claude，输入“在地图搜索金门大桥”并开始；确认地图出现 Golden Gate Bridge 标记与地点卡片，且未启动导航。接回数据线后，可用 `beanbaoagentctl status` 和本地审计复核。
2. **真人语音。** 在 BeanBao 点“🎙️ 语音输入”，清楚地说“打开地图”，点“结束录音”。核对可编辑的转写文字恰为“打开地图”，再点“开始”；确认状态完成、地图在前台。若转写不准，记录原文与显示文字，不要直接执行错误指令。
3. **实体按键与普通音量。** 在 BeanBao 打开“音量下键三连按”开关，切到设置或地图。先单按一次音量减键，确认只发生正常音量变化；再在相邻松开间隔不超过约 0.65 秒的节奏下连按三次。确认 BeanBao 打开并自动开始录音，同时正常音量行为仍存在。锁屏时重复三连按，确认不会启动录音。测试后可按需要关闭开关。
4. **当前版本重启恢复。** 在前面三项完成后重启手机，解锁并按 [真机恢复说明](device-recovery.md)重新启用 Relaxin。确认 BeanBao 包仍在、Agent 服务自动运行；在 App 输入“打开备忘录”并完成，再执行一条受限地图搜索，确认重启后的完整文字任务仍可运行。若越狱未恢复，先记录 Relaxin 页面与状态，不要反复安装 BeanBao 包。

这些是 G2–G4 当前缺少的物理证据。其他机型、其他 iOS 与越狱版本的兼容性还需要另有设备再测，不能从这台手机推断。
