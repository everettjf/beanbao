# Preserved device acceptance artifacts

These PDF reports and two Uber Eats screenshots were produced during the
November 2026 development-device trials described in
[`../build-and-test.md`](../build-and-test.md). They preserve the exact report
and visible cart evidence from those runs. The food-delivery images use the
public San Jose City Hall test address; no checkout or order was placed.

The reports contain model-generated research text and source links. They are
examples of the workflow output, not independently fact-checked technical
references. These artifacts predate the v0.3.75 app rename; they do not by
themselves validate every flow on that published build.
