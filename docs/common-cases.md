# 首批常见任务清单

更新：2026-10-30。下表按“文字入口先行，随后语音和按键”的顺序验收。所有任务只在解锁、亮屏、前台 App 与任务匹配时执行；每步观察后再动作。

| 文字指令示例 | 预期步骤 | 当前状态 | 完成判据 |
| --- | --- | --- | --- |
| 打开设置 | 观察 → 启动 `com.apple.Preferences` → 复核前台 | 真机已通过 | 前台 Bundle ID 为设置；不修改任何设置。 |
| 打开备忘录 | 观察 → 启动 `com.apple.mobilenotes` → 复核前台 | Mac 模拟代理真机已通过 | 前台 Bundle ID 为备忘录。 |
| 新建一条备忘录：测试内容 | 打开备忘录 → 点“新建” → 输入 → 点“完成” → OCR/AX 复核 | 桥接单步动作真机已通过；自然语言多步规划待端侧 Agent | 标题/正文均可见，重复运行不能误改已有笔记。测试内容须标记，便于用户删除。 |
| 在地图搜索金门大桥 | 启动地图 → 仅点搜索框 → 输入原样地点 → 提交搜索 → 复核结果 | Mac 上 Claude 受监督搜索已通过一次；端侧受限多步候选已构建、未装机 | 搜索结果出现且不启动导航。 |
| 查看 Wi-Fi 设置 | 启动设置 → 定位 Wi-Fi → 打开详情 → 读出状态 | 待模型/规则规划 | 不修改网络开关或密码；离开前台或锁屏即停。 |

首批明确排除发送消息、拨号、下单、付款、删除、安装应用、输入锁屏密码、读取任意文件。地图首次使用设置由用户明确授权后完成；这不将通用的隐私弹窗代点能力交给 BeanBao。模型可能看到截图，但若 AX/OCR 发现疑似凭据，当前代理在网络请求前停止；正式端侧版本还需把敏感画面默认不外传做成可测试的策略。
