# 首批常见任务清单

更新：2026-10-30。下表按“文字入口先行，随后语音和按键”的顺序验收。所有任务只在解锁、亮屏、前台 App 与任务匹配时执行；每步观察后再动作。

| 文字指令示例 | 预期步骤 | 当前状态 | 完成判据 |
| --- | --- | --- | --- |
| 打开设置 | 观察 → 启动 `com.apple.Preferences` → 复核前台 | 真机已通过 | 前台 Bundle ID 为设置；不修改任何设置。 |
| 打开备忘录 | 观察 → 启动 `com.apple.mobilenotes` → 复核前台 | App 与手机端真机已通过 | 前台 Bundle ID 为备忘录。 |
| 打开通讯录 | 观察 → 启动 `com.apple.MobileAddressBook` → 复核前台 | 已在当前设备确认安装并加入本地白名单；重载后的实际启动待解锁验证 | 仅打开 App，不读取联系人或发送通讯录界面给模型。 |
| 新建备忘录：测试内容 | 打开备忘录 → 点“新建” → 输入原文 → 点“完成” → 返回列表 → AX 核对完整新标题 | 旧流程在真机连续创建多条测试笔记；Agent 0.3.39 的 Palmino 逐步路径已本地测试，尚未装机 | 列表中出现完整新标题才报完成；同名标题已存在时拒绝重复创建。测试内容须标记，便于用户删除。 |
| 在地图搜索金门大桥 | 启动地图 → 必要时关闭旧地点卡片 → 点搜索框 → 输入原样地点 → 提交搜索 → 复核结果 | App Claude 与手机端服务均完成；新增同名建议、大小写与 3D 地标样本 | 地图标记和详情卡片一致，且不启动导航。 |
| 查看 Wi-Fi 设置 | 启动设置 → 定位 Wi-Fi → 打开详情 → 读出状态 | 待模型/规则规划 | 不修改网络开关或密码；离开前台或锁屏即停。 |

首批明确排除发送消息、拨号、下单、付款、删除、安装应用、输入锁屏密码、读取任意文件。地图首次使用设置由用户明确授权后完成；这不将通用的隐私弹窗代点能力交给 BeanBao。模型可能看到截图，但若 AX/OCR 发现疑似凭据，当前代理在网络请求前停止；当前手机端备忘录流程不向模型发送笔记界面；其他模型任务仍按疑似凭据检查阻止外传。
