01 / THE IDEA

Less tapping.
More done.

BeanBao turns a typed or spoken request into a small, checked sequence. It looks at the current phone state, acts inside supported apps, and reports what actually happened.

03 / GET STARTED

From release to first request.

This is a developer install for an already jailbroken RootHide phone. The tested device is an iPhone 11 on iOS 26.0.1 with Relaxin 0.5.5; other combinations need their own validation.

RootHideiphoneos-arm64eRoot shell or paired SSH
Read the full installation guide ↗
01

Download and verify

Get the `.tar` archive from a published GitHub release. Compare its SHA-256 with the release notes before transfer.

02

Run the installer

Transfer the archive to the phone. In a root shell, extract it, run the dry run, then install.

On the iPhone · root shell
mkdir -p beanbao-release
tar -xf RELEASE.tar -C beanbao-release
cd beanbao-release
sh install.sh --dry-run
sh install.sh

Replace RELEASE.tar with the exact filename you transferred.

03

Activate and configure

Reload SpringBoard once after installing Bridge, unlock, then open BeanBao. Enter your own Claude key in Model service and try Open Settings.

✦

BUILT TO STOP AND ASK

You stay in control
of the consequential steps.

App installation happens in the App Store. Email sending happens in Apple Mail. A delivery order requires an explicit checkout review and final tap. If an external action is uncertain, BeanBao pauses for reconciliation instead of replaying it.
