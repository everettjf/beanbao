少点几下，

03 / 快速上手

从安装包到第一条指令。

这是面向已越狱 RootHide 手机的开发者安装方式。目前只在 iOS 26.0.1、Relaxin 0.5.5 的一台 iPhone 11 上验证；其他组合需要单独测试。

RootHideiphoneos-arm64eroot shell 或已配对 SSH
阅读中文快速安装指南 ↗
01

下载并校验

从 GitHub Releases 下载 `.tar`，对照发布说明检查 SHA-256。

02

运行安装器

把归档传到手机。在 root shell 中解压，先预检，再安装。

在 iPhone 的 root shell 中
mkdir -p beanbao-release
tar -xf RELEASE.tar -C beanbao-release
cd beanbao-release
sh install.sh --dry-run
sh install.sh

把 RELEASE.tar 换成传入手机的实际文件名。

03

激活并配置

安装 Bridge 后重载一次 SpringBoard，解锁并打开 BeanBao。在 Model service 中填入自己的 Claude Key，然后试试 Open Settings。
