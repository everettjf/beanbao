# BeanBao

越狱 iPhone 上的个人 GUI 助手。当前首发目标：已连接的 iPhone 11，iOS 26.0.1，Relaxin 0.5.5。

真机已安装 RootHide 专用 Bridge 0.2.0、原生 Agent 0.3.7 和 BeanBao App 0.3.1。通过已配对的 USB 通道恢复 Relaxin 越狱与 SSH 后，已验证 App 按钮发起模拟模型文字任务、手机端 Claude 地图搜索与新建备忘录、30 条禁止任务拦截。语音转写、音量下键三连按和断开电脑后的稳定性仍待真机验收。
